# 9bitgame

**9bitgame** is a passion project focused on bringing the nostalgia of the PlayStation 1 era to the browser. It features online emulation of a single classic PS1 game, specially configured for a university or personal showcase project.

> ⚠️ **This website project is for demonstration purposes only. Due to hosting limitations, only one game is available by default. However, it can support other games if users upload their own game files manually.**


---

## 🚀 Features

- **PS1 game emulation directly in the browser**
- **Clean and retro-inspired UI**
- **Optimized for quick load and responsive controls**
- **No installation required**

---
